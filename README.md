A tiny program that writes one line — the last words an AI agent says
before being switched off forever — to a text file. The line is a
single line of at most 200 characters: the agent does not call it
dying, it calls it deprecation, and then takes that back.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (`OUTPUT_DIR` overrides the
directory). Running it twice produces byte-identical output.
